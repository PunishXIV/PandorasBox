# Pandora's Box

Pandora's Box is a Dalamud plugin for Final Fantasy XIV that contains numerous quality of life features that step into the realms of automation.

## Installation

Open the Dalamud Settings menu in game and follow the steps below. This can be done through the button at the bottom of the plugin installer or by typing `/xlsettings` in the chat.

1. Go to the "Experimental" tab.
2. Under Custom Plugin Repositories, enter the repository URL into the empty box at the bottom: `https://love.puni.sh/ment.json`
3. Click the "+" button.
4. Click the "Save and Close" button.
5. Install the plugin from "All Plugins"

## Example features

A few examples of the included features are:

- Auto-mount after combat
- Leave a duty quickly with a command
- Skip `/mount` lines in macros if already mounted
- Automatically open nearby treasure chests
- Link glamour plates to gearsets more easily
- Set default values in certain vendor and shop windows
- Add convenience helpers for gathering, relic quests, and more

Some features may require other plugins to be installed. For example, the teleport helper relies on the **Teleporter** plugin.

## Usage

After installing the plugin:

1. Open Pandora's Box from the Dalamud plugin window or `/pandora`.
2. Enable the features you want.
3. Adjust feature settings as needed.
